# Dileepa D - Portfolio

This repository contains the source code for my personal portfolio website, built with HTML, CSS, and JavaScript.

## Structure
- `portfolio/`: Contains the static website files (`index.html`, `style.css`, `app.js`) and image assets.
- `Dileepa_Resume.pdf`: My resume.
- `Dileepa_D_Portfolio_Profile.pdf`: Detailed portfolio profile.

## Local Development
To view the portfolio locally, simply open `portfolio/index.html` in your web browser.
